# Arc Network Automated Monitoring Agent

A lightweight, open-source automated Python script tailored for the Arc network ecosystem to monitor live RPC status, block height updates, and network latency.

## 🛠️ How to Use & Run

If you want to run this agent locally in your terminal or Termux, follow these steps:

### 1. Clone the Repository
```bash
git clone https://github.com
```

### 2. Navigate to the Folder
```bash
cd arc-monitoring-agent
```

### 3. Run the Agent
```bash
python agent.py
```
